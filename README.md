> **“兼听则明，偏信则暗”** —— 这就是 **兼听 (JianTing)** 的设计哲学。
> 这是一款基于 PyQt5 构建的跨平台**多模型并发智能对话客户端**。它打破了单点对话的限制，让您可以同时倾听多个人工智能的声音。

## 🎯 痛点与解决方案 (The Problems We Solve)

市面上的 AI 客户端普遍存在以下痛点，而“兼听”针对性地给出了解决方案：

1. **单模型的幻觉与局限**：单一模型经常一本正经地胡说八道。
   - **兼听方案**：引入多模型并发响应，将 DeepSeek、Qwen、Kimi、GLM 等顶尖大模型放在同一舞台。比对多方答案，一眼识破幻觉。
2. **长文档污染全局上下文**：上传几万字的长文档后，AI 会强制截断历史记忆，甚至把您的提问重写为“该用户上传了文档”，导致多轮对话灾难。
   - **兼听方案**：独创**“单轮临时拼接”策略**，长文档只作为背景知识注入单轮推理，绝不污染全局记忆（LangChain Memory），保证了漫长对话的不脱轨。
3. **切换历史记录时 UI 频繁假死**：随着上下文变长，本地应用在计算 Token 或进行记忆摘要时经常引发长达数秒的“未响应”。
   - **兼听方案**：全面异步化的**防卡死内存管理**。使用多线程接管所有 LangChain 摘要计算（`prune`）与文件读写，让您随时获得毫秒级如丝般顺滑的打字与界面切换体验。

## ✨ 核心亮点 (Highlights)

- 🌟 **首创“模型互评”体系**：不仅能并发对话，更能通过精准的身份上下文标签，让模型跨时空对战（例如：让 DeepSeek 直接阅读并评论 Qwen 上一秒的回答）。
- 🎨 **极其严苛的极简美学**：使用 HarmonyOS Sans 字体，调配细腻的阴影、圆角、悬浮态变色，废弃操作系统丑陋的默认 UI 组件（包括右键菜单），打造高沉浸的现代交互感。
- ⚡ **无缝多模态解析**：支持 TXT、PDF、Word (`.docx`)、Excel (`.xlsx`) 和 CSV 的本地秒级解析，直接通过可视化按钮或拖拽即可上传。
- 🔧 **高度工程化的架构**：采用 OpenAI 兼容格式对接阿里云百炼接口，轻松插拔任何新模型。

## ⌨️ 语句使用方式 (Command Syntax)

“兼听”完全由灵活的 `@` 指令体系驱动。所有的句式**必须由 `@` 起手**来复杂调用对应的模型：

1. **单点提问**
   - 语法：`@模型名 [您的问题]`
   - 示例：`@DeepSeek 帮我写一段 Python 代码`
   - *效果：仅召唤 DeepSeek 回答该问题。*

2. **并发提问**
   - 语法：`@模型A @模型B [您的问题]`
   - 示例：`@Qwen @MiniMax 比较一下 React 和 Vue 的优缺点`
   - *效果：Qwen 和 MiniMax 会同时在各自的气泡中输出观点。*

3. **群发全员**
   - 语法：`@ALL [您的问题]`
   - 示例：`@ALL 给我讲一个冷笑话`
   - *效果：一键触发所有已开启的模型进行答复。*

4. **高级用法：多模型互评（锐评）**
   - 语法：首部放负责回答的模型，正文放入被提及的模型。
   - 示例：`@DeepSeek 锐评一下 @Qwen 的回答`
   - *效果：系统会精准提取句首的 `@DeepSeek` 作为目标调用对象，并把完整的 `锐评一下 @Qwen 的回答` 传给 DeepSeek。配合系统自带的模型标签记忆，DeepSeek 会准确找到上一轮 Qwen 的言论并予以点评。*

> **提示**：如果输入框开头没有包含任何 `@` 指令，系统将默认发送给输入框左侧下拉菜单中当前选中的模型。

## 📦 Requirements (环境依赖)

运行该项目需要 Python 3.10+。请确保安装以下依赖包：

```text
# 核心 UI 与浏览器引擎
PyQt5>=5.15.0
PyQtWebEngine>=5.15.0

# 核心 AI 框架与请求
openai>=1.0.0
langchain>=0.1.0
tiktoken>=0.5.0
requests>=2.28.0

# 本地文档解析引擎
PyMuPDF>=1.23.0    # 替代原版 fitz 用于极速解析 PDF
python-docx>=1.1.0 # 用于解析 Word 文档
pandas>=2.0.0      # 用于解析 CSV 表格
openpyxl>=3.1.0    # 用于解析 Excel 工作簿
```

**安装命令：**
```bash
pip install PyQt5 PyQtWebEngine openai langchain tiktoken requests PyMuPDF python-docx pandas openpyxl
```

*(推荐在 Windows 平台运行，以获得最佳的 UI 渲染兼容性与窗口阴影效果)*

## 🚀 快速开始

1. 克隆本项目。
2. 安装上述 `Requirements`。
3. 运行 `python main.py`。
4. 首次启动时，点击左下角的 **⚙️ 设置** 按钮，填入您的 API Key（默认对接阿里云百炼平台），即可开始体验“兼听”之旅。
